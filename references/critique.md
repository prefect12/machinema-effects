# 审片：让自己像观众和导演一样判断

**为什么需要这一步**：检查脚本只能发现“可以量化的错”。“动得对不对、好不好看、观众看不看得懂”需要判断。
你看不了视频，但 `render.mjs --review` 会把运动画成图：
- `review/trail_N.png`：每段的**残影图**（0.25 秒一帧叠加）。背景清晰、移动的东西留下轨迹。
  有目的的移动 = 一条干净的路径，终点处影子最浓（停下来了）；乱晃 = 一团模糊、没有方向的重影；一直在抖 = 整个物体边缘发虚。
- `review/timeline.png`：情绪曲线、段落、每个角色的位置曲线和动作条、所有节拍在同一条时间轴上。
  角色曲线应该是**台阶**（移动 → 停住 → 移动）；**锯齿**就是来回晃。节拍应该落在动作条的边缘（动作开始/到达的那一刻）。
- `review/paths.png`：每个角色在世界里走过的**路径图**（不受镜头影响）。每 0.2 秒一个点，点稀 = 快，黄圈 = 停留（越大越久），绿字 = 每次移动的理由。
  有目的 = 一段段朝目标去的线，终点有停留圈；乱晃 = 在一小块区域里来回缠绕的线团。
- `review/seqs.png`：每段 4 帧，看同一空间是否在升级。

**规则**：先打开所有图，再逐项回答。每项必须写 **证据**（哪张图、哪个时间、看到了什么）和 **分数 1–5**。
任何一项 < 4 分：写出具体修改（改哪个时间、改成什么），改完重新 `--review`，直到全部 ≥ 4。不要给自己放水——
如果你需要犹豫才能说出“这个动作是为了什么”，那观众也看不懂，就是 ≤ 3 分。

## 整体画风合集：辨识度检查（2026-10-24）

适用：同片比较多种整体美术风格。案例：62类合集v6的新增45类中，相近绘画与手工类别被用户指出“缺少特色、有点类似”。已确认的制作问题是多类复用场景、角色轮廓及动作，主要依赖配色和纹理变化；数量与技术通过不能证明画风成立。

检查：遮住名称，把相邻类别的同尺寸关键帧和完整短片并排比较，分别记录构图、轮廓/塑形、笔触或材料构造、色彩/明暗、运动节奏的可见差异。不能辨认时写具体缺失证据，不用主观分数替代。

修正方向：按媒介重新设计场景与造型。例如铅笔的排线塑形、水粉的不透明笔触与色块、马克笔的半透明叠色与宽笔接缝应落在主体和环境的实际结构中；不能只覆盖全屏噪点。手工类别检查缝合、折叠、针脚、关节等构造如何约束形体与运动。可复用渲染工具，但不把统一角色和场景当作所有类别的必要条件。

验证状态：以上为根据v6问题提出的待验证修法；Claude重制版须重新看实际帧与动画，用户接受另记。相近类别本来允许共享艺术谱系，不能为追求差异而夸大或错误标注；无法成立的类别继续修改或按用户决定合并。
