# 用一个案例讲清特效复用

参考Xilo已归档的代码动画教程：先见到效果集合，再选一个结果解释其生成关系，接着展示可修改的需求与工具。这是组织内容的方法；不照搬其台词、角色、声音、播放量或模型能力宣称。

本次迁移选择：开头三种效果承担范围展示；表格比较承担原理和完整操作；同表换课程内容承担复用；其他效果通过目录与用途快速定位。屏幕出现“已经开源”前，实际仓库和下载必须已可用；否则使用“正在整理为可分享的Skill”。

节奏随理解任务变化：成果展示快接，重点行抬起和阴影对照保留动作完成，关键输入和导出结果可读，重复点击压缩。不能仅凭语速、配色、平均镜长模仿参考。未经实际听辨，不声称复现作者确切语气或音乐拍点。

如果旧片只改片头、正文仍按16项目录展开，应将正文改为同一案例的输入、机制、操作、结果与复用。


## 清晰度与真实操作检查

- 组织图优先使用「米白清晰版」：去掉装饰光环、减少同屏对象、扩大人物与标签。先减少信息密度，再提高源渲染分辨率；4K不能补出低分辨率素材的细节。
- 教程中的屏幕录制要放大正在修改的字段。指针强调须跟随真实指针事件，不伪造操作成功；无关浏览器/编辑台区域可以裁切。
- 裁切后等比缩放，不能将人物或文字拉宽、压扁；字幕和说明条不遮住正在解释的数字、标签。箭头终点必须对应当前讲述的那一个对象。
- 纸页高亮可通过 `paperLook.dim` 降低原文压暗程度，并设置 `highlight` 与 `translation` 颜色。浅色版中额外译文不要和正文重叠；必要时将译文移至剪辑层。
- 相机验证必须连续做「手动拖动 → 填起点终点 → 启用 → 应用 → 保存 → 导出」。逐项比较保存JSON、导出工程和实际画面；界面显示新数值不等于导出采用了新值。
- 表单回调引用的配置对象保持身份稳定。手动操作更新相机时合并进原对象，避免表单随后写入已被替换的旧对象。
